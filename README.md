# Supermarket

# Objetivo
  O objetivo desse projeto é mostrar como funciona o processo de extração de dados, tratamento e exportação dos dados tratados. Dessa forma terei uma base de dados organizada e válidada para o processo de dashboards que ajuda na criação de indicadors e insights para auxiliar os respectivos gestores em uma melhor tomada de decisões.

## Ferramentas utilizadas.
- SQL: para fazer a validação das bases no SGBD. Com isso fiz a verificação de valores nulos em colunas primary key e a verificação valores negativos em colunas quantitativas.
- PyMySQL: foi utilizado para fazer a conexão entre python e o SGBD do MySql´.
- Schedule&Time: bibliotecas que serviram como base para a criação de automação no . projeto

## Resultados esperados 
- Uma base limpa e validada
- Dados preparados para a criação de Dashboards e análise de dados.
