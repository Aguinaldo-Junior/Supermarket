# Supermarket

## Objetivo
O objetivo desse projeto é mostrar como funciona o processo de extração de dados, tratamento e exportação dos dados tratados. Dessa forma, terei uma base de dados organizada e válida para o processo de dashboards, que ajuda na criação de indicadores e insights para auxiliar os respectivos gestores na tomada de decisões.

## Ferramentas utilizadas
- SQL: para fazer a validação das bases no SGBD. Com isso fiz a verificação de valores nulos em colunas de primary key e a verificação de valores negativos em colunas quantitativas.
- PyMySQL: foi utilizado para fazer a conexão entre Python e o SGBD do MySQL.
- Schedule e Time: bibliotecas que serviram como base para a criação de automação no projeto.

## Resultados esperados
- Uma base limpa e validada.
- Dados preparados para a criação de dashboards e análise de dados.
